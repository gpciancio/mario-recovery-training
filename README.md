# Mario Recovery Training

Mobile-first, single-file Planet Fitness restoration workout tracker. Built as a portfolio-friendly static site designed around an iPhone screen.

## Features
- Five-day weekday schedule; three strength-activation days and two recovery/mobility days during restoration.
- Three selectable phases: recovery (Nov 20–Dec 1, 2026), week 5 (Dec 2–8), and week 6 (Dec 9–15).
- Daily exercise checklists, completion progress, effort ratings, and journaling.
- Browser-local persistence via `localStorage`, with JSON export/import backup.
- iPhone safe-area padding, large touch targets, fixed bottom navigation, and no third-party dependencies.
- No accounts, tracking, analytics, or server-side personal data storage.

## Run locally
Open `index.html` in a browser or use a static file server.

## Deploy on Render
- Type: Static Site
- Repository: `gpciancio/gp-recovery-training`
- Branch: `main`
- Build command: `echo 'Static site ready'`
- Publish directory: `.`
- Auto-deploy: enabled

## Important
The workout schedule is informational, not medical advice or surgeon clearance. Resistance training prior to 30 days following hair transplant requires specific surgeon approval. Later progression is conditional on normal healing and medical clearance. Do not train through scalp discomfort, perspiration, pressure, swelling, or knee pain.

## Privacy
Workout notes and progress are saved to the device/browser, not GitHub or Render. They do not sync across browsers/devices. Export backups regularly if you want to preserve progress.
